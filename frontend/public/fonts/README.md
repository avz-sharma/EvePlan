# Local font subsets

Source Sans 3 and Source Serif 4, Fontsource Variable package version 5.3.1. These are the publisher's Latin WOFF2 subsets, with the variable weight axis retained. Their SIL Open Font Licenses are included here. Other writing systems fall back to the system fonts.

Assets have a SHA-256 prefix in their filenames and are preloaded by the document. CSS uses `font-display: swap`. They require no third-party font request or runtime package.

Sources: `@fontsource-variable/source-sans-3/files/source-sans-3-latin-wght-normal.woff2` and `@fontsource-variable/source-serif-4/files/source-serif-4-latin-wght-normal.woff2` from their 5.3.1 npm packages. Refresh the filename hash, preload URL, CSS URL, and license when updating an asset.
