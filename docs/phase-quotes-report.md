# Saved quotation implementation

Implemented all seven categories with stable quotation/vendor/event IDs, original/finalized amounts, notes, conditions, budget caps, editing/removal, shared Quotes/Vendors records, branch isolation, browser persistence and undo/redo. Only selected finalized offers affect budgets. Catering replaces the selected event estimate, and one plan-wide reserve is applied. Budget shows provision, reserve, remaining funds and additional funds needed. Comparison remains usable without AI; explicit bounded AI analysis validates structured output, caches unchanged inputs and hides stale suggestions.

Assumptions: finalized zero is valid; missing finalized amounts cannot be selected. Contingency defaults to 10% and is editable plan-wide from 0 to 100%. Prompt only when a new quotation introduces the second distinct vendor; edits, third offers and reloads do not prompt. Removing events/days removes linked quotations; undo restores them. Existing assignments retain allocation until explicitly replaced by a selected quotation; replacing removes the old assignment so deleting the quotation cannot resurrect old spending. Existing transient quote comparison and Maps discovery remain available. No proposal document is published.

Verification: use README quality commands plus the new saved_quotes and savedQuotes tests and the mobile/desktop saved quotation Playwright journeys. Docker is unavailable locally; the user approved committing after local checks and running the container check in GitHub Actions. AI provider behavior is tested with mocks, without consuming live quota.

Validation results: 105 backend tests; 44 frontend tests; all six browser journeys including desktop/mobile quote selection and reload. Backend coverage exceeds 70% overall and 80% engine; frontend lines exceed 70%. Ruff, strict mypy, TypeScript/ESLint, unused checks, production build, Bandit and both dependency audits pass. A clipped accessible budget table was wrapped to prevent mobile horizontal overflow. The full Git-history secret scan is clean.
